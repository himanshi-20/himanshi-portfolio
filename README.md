# Himanshi Jain — Portfolio

A responsive React portfolio with a premium black-and-white visual direction and lime accent.

## Run locally

1. Install Node.js (18+ recommended).
2. Open this folder in VS Code or a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

## Build for deployment

```bash
npm run build
```

The production site is generated in `dist/`. Deploy it to Vercel, Netlify, or any static hosting provider.

## Before publishing

Update these placeholders in `src/main.jsx`:
- `YOUR_EMAIL@example.com` with your professional email.
- LinkedIn URL with your profile.
- GitHub URL with your profile.
- Add live project URLs where available.
- Add your exact college name, degree details, and any professional experience/internship details you want displayed.

The project descriptions are based on the information currently available and should be reviewed for accuracy before sharing with recruiters.
